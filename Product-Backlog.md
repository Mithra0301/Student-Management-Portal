# Student Management Portal – Product Backlog

**Course:** 26CS102 – Foundation of Full Stack

## Product Backlog Items

| ID   | User Story                                                                                                 | Priority |
| ---- | ---------------------------------------------------------------------------------------------------------- | -------- |
| US01 | As a visitor, I want to view the Home page so that I can learn about the portal.                           | High     |
| US02 | As a visitor, I want to view the About page so that I can understand the purpose of the portal.            | Medium   |
| US03 | As a student, I want to register through the Student Registration page so that my details can be recorded. | High     |
| US04 | As a student, I want to view available courses so that I can learn about them.                             | High     |
